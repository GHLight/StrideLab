# StrideLab 项目与现有应用比对

核对对象：已交付的 `StrideLab-v0.1-debug.apk`、项目源码归档、GitHub main（28157b2）、最新开发分支（6dcba38）、PRD 和仓库内 synthetic-running-data。核对基于实际文件、源码差异和构建日志，不按文件标题推断完成度。

## 哪个才是最新

- 最新已交付 APK：v0.1，34,221 字节，2026-11-27 12:45（北京时间）保存。其 core.js、index.html、map-reference.js 与归档相同，ui.js 有恢复相关差异。

- 仓库中的算法工具已经是 Skill V2.0，不应回退到 V1.1。Python 工具的能力不等于 Android 已实现的能力。
- 之前临时工作区的增强实现未提交，环境重启后已丢失；此前测试不能替代当前候选的验收。继续开发以已提交源码为基础。

## 功能取舍

| 功能 | 已交付 APK / 主分支 | 最新开发分支 | 整合决定 |
|---|---|---|---|
| 低饱和 UI、矢量图标 | 已有 | 沿用 | 保留，不重新设计 |
| 地图初始位置 | 低缩放全球视野，需手动操作 | 自动请求前台位置，恢复视野，定位精度圈 | 保留开发分支 |
| 地点搜索 | 缺失 | Android Geocoder 与搜索结果保护 | 保留；设备服务可用性仍需验收 |
| 多点参考编辑 | 添加、删除、逆序、基本撤销 | 插入、移动、撤销/重做、草稿、收藏、切换撤销 | 保留开发分支全部操作 |
| 街道 / 卫星切换 | 仅 OSM | 仅 OSM | 整合 Esri 街道/影像及 OSM 选项；保留来源说明 |
| 日期、时间、时区 | 缺失 | 选择日期时间，固定/随机日期间隔 | 保留开发分支，导出使用生成时快照 |
| 配速 / 时长 | 距离与配速 | 可切换距离+时长 | 保留开发分支 |
| 历史结果 | 基础恢复 | 最多50个项目、确定性重放、备份导入 | 保留并测试；不变更旧模型结果 |
| FIT / TCX | 固定50m/30s格式夹具 | 仍是固定夹具 | 保留夹具，另加所选实际合成样本导出，不能混淆 |
| 核心模拟 | 固定1秒、单组、简单误差 | 与主分支相同 | 暂保留，后续引入新模型版本与旧版本重放 |
| Python工具 | V2.0：分组、相关误差、独立随机流等 | 未接入Android | 保留工具，不把工具能力算作App完成 |
| 返回导航 | 系统返回退出 | Web页面返回，但Java语法错误 | 修复语法，保留返回行为 |
| Android架构 | Java + WebView | 同左 | 如实保留；尚未实现PRD的Compose/Room/地图SDK架构 |

## 本轮推进

1. 修复 MainActivity 返回键回调中的非法反斜杠，首次修复提交 dd48a16 已在 CI 通过 APK 编译、Lint、核心与浏览器回归。
2. 新增独立 session-formats.js，导出所选已保存样本的 FIT/TCX。时间取生成快照，修改表单但未重新生成不会改变旧样本。FIT/TCX 保留 SYNTHETIC_RESEARCH，局部坐标不伪装为 GPS。
3. FIT/TCX 步频采用周期/分钟，CSV 仍为步/分钟。对时间轴、逐点数据、汇总一致性进行导出前验证；不合格数据给出错误，不静默修正。
4. 街道/卫星/OSM切换保留节点、视野、草稿、收藏与撤销栈；完整地图来源说明可展开查看。仍是瓦片渲染器，不能标作地图SDK完成。
5. 扩充独立格式验证与浏览器回归，补充使用说明。

## 验收边界

- 已实际运行：Node核心回归；Python V2工具12项测试；手机尺寸浏览器交互；历史重放导出的ZIP逐字节一致；所选样本导出与快照绑定；FIT独立fitdecode解析及CRC；TCX官方XSD；UTC跨日/不同时区；步频换算、逐点里程与速度误差界限。
