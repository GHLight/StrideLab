# StrideLab 使用说明

StrideLab 生成明确标记的合成研究数据，适用于教学、统计分析和授权软件测试。结果不是实际运动或传感器实测，生理模型未经人体校准。

## 场地与地图

首次进入会请求前台定位权限。授权后显示当前位置；拒绝或定位不可用时可以搜索学校、道路等地名，或展开“手动坐标与地图工具”。地图中心的准星用于精确选点，单指平移、双指或加减按钮缩放。“扩大地图”可增加编辑面积。

在“底图”中选择OpenStreetMap街道或Esri卫星。加载失败可以换底图或重试。卫星图不保证有地名，影像日期和精度取决于服务商。缩放到19级以上是放大已有图像，不会增加真实细节。地图服务收到当前视野的瓦片请求，模拟记录不随之上传。

逐次“添加中心点”，在节点列表中选择后可移动、插入、删除、逆序、撤销和重做。闭合路线会连接首尾；开放路线不连接。展开“场地收藏”可命名保存并重新打开。收藏与正在编辑的草稿分别保存。

地图标点可用于生成局部研究路线。沿场地边缘顺序选点（推荐4–10个，复杂弯道可增加标点）；选择闭合或开放路径、直线或平滑插值、节点总数（最多120，包含原始节点）以及平滑程度。预览保留原标点顺序和局部米制尺度，不再强制400米或椭圆。地图上的虚线是参考连线，标点按钮下方显示插值预览。点击“使用预览路线并配置模拟”进入模拟页，当前路线可在高级编辑器中撤销或修改。WGS-84参考点单独保存并可导出GeoJSON；局部合成运动不保留地理锚点。历史实验保留原始快照。

## 生成与分析

在“模拟”页设置次数、距离，以及配速或时长。选择日期、时间、UTC偏移，日期间隔可以固定或在范围内随机；保存种子后可重现同一实验。设置起点、方向、疲劳、速度波动和观测误差，再点击生成。

当前Android实现单批1–30条、固定1秒采样，受总采样点上限约束。开放路线的目标距离不能超过路线长度。0误差时观测点与理想点重合。

在“分析”切换样本查看路线、速度、心率和步频。模型里程由速度积分得到；观测里程受噪声影响，可能明显偏大，不应理解为实测里程。

## 导出

文件中心分为批量导出、单条样本、实验配置与项目历史、高级工具和说明。点击“导出 N 个 FIT · ZIP”可将当前已生成实验的全部非地理合成 FIT 样本保存为一个 ZIP，内含独立文件、manifest.json 和用途声明。在“数据来源与使用说明”可单独导出同一份TXT声明。用途声明不构成免除全部法律责任的保证。它不会将地图参考点附加到合成活动。时间轴不完整的历史实验不可批量导出 FIT；不会静默跳过无效样本。


“文件”页先查看导出内容说明，选择样本后导出CSV、FIT或TCX，或独立导出带合成标识的局部轨迹 SVG 图。FIT/TCX包含所选样本的时间、模型里程、速度、心率、步频和合成标识，不含GPS位置。FIT/TCX步频单位为周期/分钟，CSV为步/分钟，数值约相差一倍是单位转换。

导出基于已经生成并保存的实验。仅修改表单不会改写旧实验；需要重新生成才能得到新参数对应的文件。未设置时间轴的历史样本不能直接导出当前样本FIT/TCX；请保留历史数据，另行生成有时间轴的实验。FIT时间不能早于1989-12-31。

“高级工具 · 格式测试”包含固定50m/30s非地理夹具，以及独立的四点海域GPS坐标测试夹具；均与当前实验无关。它和“导出所选FIT/TCX”是两个不同入口。

完整研究ZIP包含逐点CSV、汇总、配置快照、时间轴（如有）和用途声明。Android点击导出后需在系统文件选择器确认位置并保存；取消选择器不会产生文件。FIT和TCX分别要求最终文件名以.fit及.tcx结尾；应用尝试纠正文件提供器自动附加的.bin或.xml，保存后核对实际文件名。若提供器不允许更名，将提示更换保存位置，不能视为后缀验收通过。TCX内部本来就是XML结构；更名不增加或删除轨迹字段。未经验证的第三方应用导入兼容性不作保证。

## 历史与备份

文件页可以打开历史项目、备份与导入项目JSON。当前打开的实验不能删除；删除其他项目需再次点击确认。清除应用数据或卸载前，请先备份项目和导出参考点，并在其他位置保留文件。

返回键优先返回应用内上一页面。请勿把浏览器测试视作全部Android设备验收；定位、地名搜索依赖设备和网络服务。测试APK签名可能与既有安装不同，若系统提示签名冲突，先保留旧安装和备份，不要为安装新包而直接清除数据。
