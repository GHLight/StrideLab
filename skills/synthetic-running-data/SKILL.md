# StrideLab · Synthetic Running Data V2.0

## 范围
用于学习交流、教学、运动科学模拟、统计分析及授权软件测试。输出为合成数据而非实测值，不用于真实评测。不需要 App、地图 SDK、模拟定位权限或在线服务。地理场地是独立参考层；合成运动采用局部米制坐标。固定 FIT/TCX 格式测试夹具与批量研究数据分离，不连接或优化第三方成绩系统。

## 1. 一次性询问（已有参数不重复问）
基础模式先询问：
- 路线：可上传有序参考点（不限四点），或四个方向的经纬度；说明是 WGS84 还是 LOCAL_M，以及路线开放或闭合。默认独立400m标准环形模型。用户可直接提供地图上选取的坐标，无需现场采集。不要凭截图认定精确测绘坐标。
- 组数、每组次数（固定、逐组列表或随机区间）、距离（固定或范围）、配速或时长（二选一）。
- 示例日期、日期间隔、当地起跑时间段及 UTC 偏移。
- 起点随机开关、方向、GPS观测误差、速度波动；提供下表和实际局部预览。其余高级项可选。

| 参数 | 默认 | 含义 |
|---|---|---|
| GPS误差 gps_noise_m | 1.5 m | 长期二维 RMS 目标，0–30 m，不是最大偏差 |
| 速度波动 speed_cv_pct | 5% | 稳定阶段速度变异系数目标，0–20%，报告实际CV |
| 随机起点 random_start | true | 闭合路径可随机或固定弧长；开放路径固定在方向对应端点 |
| direction | forward | forward / reverse / random |
| fatigue | normal | none / normal / high |
| scenario | steady | steady / progressive_slowdown / interval |
| 起跑/结束阶段 | true / true | 独立加速和减速开关 |

误差尺度示意：0m为零观测噪声；1.5m为小尺度扰动；3m、6m、12m依次扩大误差实验尺度；更大数值为压力测试。实际效果以本地生成的 preview.svg 和 RMS 为准，不预测第三方地图表现。速度CV 0%关闭随机波动（疲劳、阶段趋势仍可能使实际CV非零）；5%为基础示例；10%、20%为更高变化的敏感性实验。不是实测人体等级。

## 2. 参数规则
用户已给出的值优先，不暗中修改。缺省值见 example_config.json 和 references/configuration.md。若用户明确要求默认生成，无需再问。若已提供的参数存在硬冲突（例如开放路径太短、未确认坐标系、重复节点），一次性报告冲突，不拼接假坐标或静默缩放。仅缺少可选参数时自动补全，记录 automatic_fields。坐标系不明时可以改做独立局部默认实验，但原输入另存并明确说明，不冒称已转换。已知 WGS84 输入可导出独立 GeoJSON；GCJ02/BD09 等需经可信工具转换并保留来源，本脚本不转换。

## 3. 执行与交付
使用 Python 3.10+（标准库，无额外依赖），按配置实际运行：
```sh
python scripts/generate.py --config example_config.json --output ./generated
```
无 config 使用默认值。必须使用新目录，不覆盖先前实验。查看 summary.csv、manifest.json、group_XX/preview.svg；检查模型积分距离、实际配速、实际CV、实际RMS、观测距离偏差及异常警告。路径默认按有序节点折线与弧长插值；保留节点，四点仅作粗略参考，不认定实测周长。标准虚拟跑道是两直道加两半圆；不强行把用户路线缩放为400m。交叉路段列出警告。

同一组可共享虚拟运动者，或组间独立档案。运动、定位误差、生理指标使用独立随机流；速度积分与步频步幅保持一致。所有指标是未校准模型，不能作为实证结论。模型距离、观测累计距离分别保存，误差大于5%提示，不修改原始结果。模型配置、随机种子、引擎版本、每条记录摘要、SHA256及用途声明随包保存。输出研究 CSV/JSON 与 ZIP。单条记录用 `--only group_01_run_001` 重放，`--revision 1` 生成新变体；使用原项目 `replay_config.json`，写入新目录，不改动其他记录。

FIT/TCX 独立格式测试命令：
```sh
python scripts/format_fixture.py --output ./format_fixture
```
固定短距离、无真实地理坐标的测试夹具，不是批量研究数据的导出格式。不可宣称官方 SDK、实机导入或生理校准已通过，除非实际验证。

每组和总 ZIP 均须包含 `用途声明.txt`，CSV 每行、JSON 每条会话均标明合成来源。交付实际生成的文件链接，不提供未验证的路径。简要说明模型假设、异常与未验收项，不重复要求用户手动调试。

## 4. 验收
```sh
python scripts/test_skill.py
```
确认默认生成、多点、开放路径、坐标参考隔离、零噪声、误差与生理指标独立、固定起点、方向、时长联动、指标选择、种子复现、批量、单条重放、声明与格式测试。测试不是第三方软件兼容性或人体生理真实性认证。
